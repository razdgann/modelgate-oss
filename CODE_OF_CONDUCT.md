# Code of Conduct

We are committed to a welcoming, harassment-free project. Be respectful, assume good intent, accept constructive feedback, and focus disagreement on ideas. Harassment, threats, discrimination, and publication of others' private information are unacceptable. Maintainers may remove content or participation that violates these standards. Until the repository owner publishes a dedicated conduct contact, report concerns privately to a repository maintainer through their public GitHub profile.
