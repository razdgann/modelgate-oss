# Contributing

Thanks for improving ModelGate OSS. Open an issue before substantial changes. Keep provider responses compatible, never persist credentials, add mocked tests, and avoid analytics work on the streaming hot path. Run `npm test`, `npm run lint`, `npm run typecheck`, and `npm run build` before submitting a pull request. By contributing, you agree your contribution is licensed under Apache-2.0. Licensing should be reviewed before accepting unusually large contributions.
